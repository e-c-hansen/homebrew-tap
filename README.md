# homebrew-tap

Homebrew tap for [MiniCode](https://github.com/e-c-hansen/homebrew-tap), a tiny
native macOS code editor.

## Install

```
brew install --cask e-c-hansen/tap/minicode
```

The app is ad-hoc signed but not notarized, so the cask clears the macOS
quarantine flag on install and it opens without a Gatekeeper warning.
